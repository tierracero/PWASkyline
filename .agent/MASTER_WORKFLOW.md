# Master Workflow

Canonical workflow entry for tooling that expects a master workflow document.

PWASkyline uses the mandatory workflow defined in `WORKFLOW.md`:

**PLAN -> IMPLEMENT -> AUDIT**

## Required Reading

1. `AGENTS.md`
2. `SYSTEM_RULES.md`
3. `WORKFLOW.md`
4. `COMMIT_RULES.md`
5. `SKILL_INDEX.md`
6. `ARCH_INDEX.md`
7. `SOURCE_MAP.md` before source-touching work

## Completion Standard

No task is complete until the implementation is verified, stable docs are synchronized, and git status confirms no unintended changes.
